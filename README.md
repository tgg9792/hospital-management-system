# 医院管理信息系统

## 项目简介

本项目是一个基于 Python + MySQL 的医院管理信息系统，实现了门诊和住院两大核心业务模块。系统支持管理员、医生、病人三种角色登录，分别完成不同的业务操作。

## 技术栈

编程语言: Python 3.10
数据库: MySQL 8.0
数据库驱动: mysql-connector-python
图形界面: tkinter

## 系统功能

### 管理员功能
- 管理科室（增删改查）
- 管理医生（增删改查，自动创建登录账号）
- 管理药品（增删改查）

### 医生功能
- 查看排班
- 接诊病人（开处方、填写症状、添加药品）
- 查看历史处方
- 办理住院（分配病房床位）
- 每日诊疗（记录住院病人每日症状和诊疗方案，自动计算费用）

### 病人功能
- 挂号（选择科室和医生）
- 缴费（缴纳门诊处方费用）
- 查询就诊记录
- 查询费用明细（查看处方药品清单）
- 缴纳预交费（住院预交费用）
- 查询住院档案
- 查询住院记录

## 安装与运行

### 1. 环境要求
- Python 3.6 或更高版本
- MySQL 5.7 或更高版本

### 2. 安装依赖
pip install mysql-connector-python

### 3. 导入数据库
mysql -u root -p < hospital.sql

或在 MySQL 命令行中执行：
source hospital.sql

### 4. 修改数据库配置
编辑 db_config.py，填入正确的 MySQL 用户名和密码

### 5. 运行程序
python main.py

## 使用说明

### 门诊流程
1. 病人登录 -> 挂号（选择科室和医生）
2. 医生登录 -> 接诊病人 -> 填写症状 -> 添加药品 -> 确认开处方
3. 病人登录 -> 缴费 -> 选择未缴费处方 -> 确认支付

### 住院流程
1. 医生登录 -> 办理住院 -> 选择病人 -> 分配病房床位
2. 病人登录 -> 缴纳预交费 -> 输入金额 -> 确认
3. 医生登录 -> 每日诊疗 -> 选择住院病人 -> 填写症状和诊疗方案 -> 添加药品 -> 保存
4. 病人登录 -> 查询住院档案 / 查询住院记录

## 数据库表结构

department: 科室表
doctor: 医生表
patient: 病人表
drug: 药品表
user: 用户登录表
registration: 门诊挂号表
prescription: 门诊处方表
prescription_item: 处方明细表
payment: 门诊缴费表
ward: 病房表
bed: 病床表
inpatient_archive: 住院档案表
inpatient_record: 住院记录表

## 注意事项

- 医生职称影响诊疗费：主任医师50元，副主任医师40元，主治医师30元
- 开处方时会自动扣减药品库存
- 办理住院时预交费默认为0，需病人自行缴纳
- 每日诊疗会自动计算当日费用（床位费 + 药品费）
